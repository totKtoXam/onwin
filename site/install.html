Установка onwin

Проще всего — одной командой в Терминале. Та же команда потом обновляет приложение и движок.

Через Терминал рекомендуем

Скопируйте команду, вставьте её в Терминал и нажмите Return.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

  1. Откройте Терминал

    Нажмите ⌘ + Пробел, введите «Терминал» и нажмите Return.

  2. Вставьте команду

    Нажмите ⌘ + V в окне Терминала.

  3. Нажмите Return

    Дождитесь сообщения о завершении. Если на Mac нет Rosetta 2, скрипт предложит её установить.

Что устанавливается

Приложение
Onwin.app в папку «Программы» (/Applications)
Движок Wine
отдельно, в ~/Library/Application Support/onwin/Engines

Обновление

Чтобы обновиться, выполните ту же команду ещё раз. Скрипт скачает только то, что изменилось: приложение — это десятки мегабайт, а движок весит сотни и загружается заново, только когда выходит его новая версия.

Скрипт можно прочитать перед запуском: install.sh. Файлы, загруженные через Терминал, macOS не помечает как скачанные из интернета, поэтому приложение откроется сразу, без предупреждений Gatekeeper.

Образ диска (DMG)

Другой способ — скачать полный образ: приложение с движком внутри. Обновлять его придётся вручную, каждый раз загружая образ целиком.

Скачать DMG Последний выпуск на GitHub
  1. Откройте скачанный файл и перетащите Onwin в папку «Программы».
  2. Запустите Onwin из папки «Программы» — при первом запуске понадобится один дополнительный шаг (см. ниже).

Первый запуск и Gatekeeper

onwin не заверен (notarized) в Apple: для этого нужна платная учётная запись разработчика, которой у проекта пока нет. Поэтому macOS заблокирует первый запуск приложения, скачанного через браузер. Разрешить его можно так:

  1. Откройте Onwin один раз. macOS сообщит, что не может проверить приложение, — нажмите «Готово».
  2. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
  3. Прокрутите до раздела «Безопасность» и нажмите «Открыть всё равно» рядом с сообщением об Onwin. Подтвердите паролем или Touch ID.

Дальше приложение открывается как обычно. Установка через Терминал обходится без этих шагов.

Удаление

Эта команда удалит приложение и движок. Ваши пространства — установленные программы, игры и сохранения — останутся на месте.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

Чтобы стереть и пространства, добавьте --purge. Это необратимо: программы и сохранения внутри пространств будут удалены.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge
