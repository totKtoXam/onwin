Установка onwin

Два способа — выберите тот, что удобнее. Результат одинаковый: onwin в папке «Программы».

бета Сейчас доступны бета-версии: onwin ещё в разработке, что-то может работать нестабильно. Если столкнётесь с проблемой — напишите нам.

Способ 1

Скачать приложение

Обычный образ диска (DMG), как у других программ для Mac. Всё нужное уже внутри.

Скачать onwin (DMG) Последний выпуск на GitHub

  1. Откройте скачанный файл

    Он появится в «Загрузках». Перетащите Onwin в папку «Программы».

  2. Запустите Onwin

    В первый раз macOS скажет, что не может проверить приложение. Нажмите «Готово».

  3. Разрешите запуск один раз

    «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Открыть всё равно». Подробнее, почему так

Способ 2

Через Терминал без предупреждений

Одна команда — и onwin установится сам, без шагов в Системных настройках.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

  1. Откройте Терминал

    Нажмите ⌘ + Пробел, введите «Терминал» и нажмите Return.

  2. Вставьте команду

    Нажмите ⌘ + V в окне Терминала.

  3. Нажмите Return

    Дождитесь слова «Готово». Если на Mac нет Rosetta 2, установщик предложит её поставить.

Обновления

Скачать новую версию можно так же: новый образ диска или та же команда в Терминале. Команда скачивает только то, что изменилось. В ближайших версиях onwin будет сам предлагать обновиться — одной кнопкой, без повторных разрешений.

Все выпуски, что в них нового и команды для установки любой версии — на странице «Обновления».

Приложение
Onwin.app в папке «Программы» (/Applications)
Движок Wine
при установке через Терминал — отдельно, в ~/Library/Application Support/onwin/Engines; в образе диска — внутри приложения

Скрипт установки можно прочитать перед запуском: install.sh.

Почему macOS спрашивает разрешение

Apple проверяет (заверяет) программы только за платную подписку разработчика — 99 долларов в год. У onwin её пока нет, поэтому при первом запуске приложения, скачанного через браузер, macOS осторожничает и просит подтвердить, что вы доверяете программе. Это нужно сделать один раз:

  1. Откройте Onwin из папки «Программы». Появится сообщение, что macOS не может проверить приложение, — нажмите «Готово».
  2. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
  3. Прокрутите до раздела «Безопасность» и нажмите «Открыть всё равно» рядом с сообщением об Onwin. Подтвердите паролем или Touch ID.

Код onwin открыт — его может проверить любой. Установка через Терминал обходится без этих шагов, потому что файлы, скачанные командой, macOS не помечает как «из интернета». Пожертвования помогут оплатить подписку Apple, и тогда этот шаг исчезнет совсем.

Удаление

Эта команда удалит приложение и движок. Ваши пространства — установленные программы, игры и сохранения — останутся на месте.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

Чтобы стереть и пространства, добавьте --purge. Это необратимо: программы и сохранения внутри пространств будут удалены.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge
