许可证全文与源代码

所有许可证的完整文本都随应用一起提供，位于 THIRD_PARTY_NOTICES 文件中。

每个引擎版本中所有 LGPL 和 GPL 组件的源代码，都附在 GitHub 上对应的发布版本中：打开 Releases，选择标签以 engine- 开头的版本。

不包含的内容

Game Porting Toolkit 中的 D3DMetal 归 Apple 所有，onwin 不分发它。如果您想使用它，在您用自己的 Apple ID 登录后，onwin 会从 Apple 网站下载 Game Porting Toolkit，并在您的 Mac 上导入。它的使用受 Apple 许可证约束。
