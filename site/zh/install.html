安装 onwin

两种方式，任选其一。结果相同：onwin 会出现在“应用程序”文件夹中。

测试版 目前提供的是测试版：onwin 仍在开发中，部分功能可能不够稳定。如果遇到问题，请联系我们。

方式 1

下载应用

普通的磁盘映像（DMG），和其他 Mac 程序一样。所需的一切都已包含在内。

下载 onwin（DMG） GitHub 上的最新版本

  1. 打开下载的文件

    它会出现在“下载”文件夹中。将 Onwin 拖到“应用程序”文件夹。

  2. 打开 Onwin

    首次打开时，macOS 会提示无法验证此应用。点按“完成”。

  3. 允许运行一次

    “系统设置” → “隐私与安全性” → 在底部点按“仍要打开”。为什么需要这样做

方式 2

通过“终端” 无安全提示

只需一条命令，onwin 就会自动安装，无需在“系统设置”中进行任何操作。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

  1. 打开“终端”

    按下 ⌘ + 空格键，输入“终端”，然后按 Return。

  2. 粘贴命令

    在“终端”窗口中按下 ⌘ + V。

  3. 按下 Return

    等待出现 «Готово»（俄语，意为“完成”）。如果 Mac 上没有 Rosetta 2，安装程序会提示您安装。

安装程序目前用俄语显示提示信息，操作步骤与上面相同。

更新

获取新版本的方法相同：下载新的磁盘映像，或在“终端”中运行同一条命令。命令只会下载有变化的部分。在接下来的版本中，onwin 将会主动提示更新：只需点一下按钮，无需再次授权。

所有版本、更新内容以及安装任意版本的命令，都在“更新”页面。

应用
“应用程序”文件夹（/Applications）中的 Onwin.app
Wine 引擎
通过“终端”安装时，单独存放在 ~/Library/Application Support/onwin/Engines；使用磁盘映像时，位于应用内部

运行前可以先阅读安装脚本：install.sh。

为什么 macOS 会要求确认

Apple 只为购买了付费开发者订阅（每年 99 美元）的程序进行验证（公证）。onwin 目前还没有这项订阅，所以首次打开从浏览器下载的应用时，macOS 会比较谨慎，要求您确认信任这个程序。只需操作一次：

  1. 从“应用程序”文件夹打开 Onwin。会出现“macOS 无法验证此应用”之类的提示，点按“完成”。
  2. 打开“系统设置” → “隐私与安全性”。
  3. 向下滚动到“安全性”部分，在关于 Onwin 的提示旁点按“仍要打开”。用密码或触控 ID 确认。

onwin 的代码是开源的，任何人都可以检查。通过“终端”安装则不需要这些步骤，因为 macOS 不会把用命令下载的文件标记为“来自互联网”。捐款将帮助支付 Apple 的订阅费用，届时这一步就会完全消失。

卸载

此命令会删除应用和引擎。您的空间（包括已安装的程序、游戏和存档）都会保留。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

如果要连空间一起删除，请加上 --purge。此操作无法撤销：空间中的程序和存档都会被删除。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge
