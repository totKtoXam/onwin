文档

用简单的话讲清楚怎么使用 onwin。建议从“快速入门”开始：五分钟后，您的 Mac 上就能运行第一个 Windows 游戏或程序。

快速入门

从安装到运行第一个游戏只需五步，不需要任何手动设置。

  1. 安装 onwin

    打开“终端”：按 ⌘ + 空格键，输入“终端”，然后按 Return。粘贴下面这条命令，再按一次 Return：

    curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

    这条命令会安装 onwin 应用及其引擎。引擎是负责运行 Windows 程序的那一部分。安装过程中“终端”里的提示目前是俄语的。其他安装方式请见“安装”页面。

  2. 打开 onwin

    onwin 位于“应用程序”文件夹中。如果 Mac 上没有 Rosetta 2，onwin 会显示“onwin 需要 Rosetta 2”窗口。Rosetta 2 是 Apple 提供的免费转译工具：没有它，Windows 程序无法在搭载 Apple 芯片的 Mac 上运行。点按“安装 Rosetta”。macOS 可能会要求输入密码，这是正常的。

    接下来您会看到主窗口。左侧是各个栏目：“桌面”、“应用和游戏”目录、您的空间、正在运行的程序以及日志。右侧是“桌面”：您所有的 Windows 游戏和程序都会出现在这里。

  3. 安装 Steam 或您自己的程序

    一键安装 Steam。在空白的桌面上点按“安装 Steam”。或者在左侧打开“应用和游戏”，找到 Steam，然后点按“安装…”。onwin 会自动准备好一切并运行安装程序。

    您自己的程序，也就是 .exe 或 .msi 安装文件。有三种方法：

    • 直接把文件拖到 onwin 窗口中；
    • 把文件拖到 Dock 中的 onwin 图标上，或者用 onwin 打开它（在“访达”中：右键点按 →“打开方式”→ onwin）；
    • 在目录的“自定义程序”部分，点按“选择安装程序…”。

    onwin 会询问把程序安装到哪里：新的空间，还是已经创建的某个空间。如果拿不准，就选新的。

  4. 运行游戏

    安装好的所有内容都会以磁贴的形式出现在 onwin 的“桌面”上。双击磁贴，程序或游戏就会启动。您在 Steam 中下载的游戏也会作为单独的磁贴出现在这里。

  5. 新游戏请启用 D3DMetal

    现代游戏（DirectX 12，很多 DirectX 11 游戏也一样）使用 D3DMetal 效果最好，这是 Apple 的图形技术。onwin 不能把它打包在内，但可以替您安装：打开目录中的“组件”部分，找到“D3DMetal (Game Porting Toolkit)”卡片，点按“安装 D3DMetal”。需要用免费的 Apple ID 登录。详情请见“图形”一节。

    如果游戏需要 D3DMetal 而它还没有安装，onwin 会在启动前主动提示您安装。

空间

空间是 onwin 里一台独立的“Windows 电脑”。它有自己的 C: 盘，自己的程序、设置和存档。各个空间互不干扰。如果出了问题或者不再需要，删除这个空间即可，程序不会留下任何痕迹。

通常一个启动器（例如“Steam”）或一个程序用一个空间就够了。从目录安装时，onwin 会自动创建空间。

创建空间

在左侧的“空间”部分点按“创建空间…”。也可以点按窗口顶部的“新建空间”按钮，或者按 ⌘ + N。填写名称并选择 Windows 版本。大多数游戏适合 Windows 10。图形可以保持“自动”。

可以对空间做什么

在左侧列表中右键点按某个空间。空间页面上的“更多”菜单里也有同样的命令。

  • “重新命名…”：换一个名字。请先关闭这个空间中的程序。
  • “复制”：制作一个独立的副本，包含所有已安装的程序。想尝试点什么、又不想影响正在使用的版本时很方便。
  • “归档…”：把空间打包成一个 .onwinspace 文件。可以用作备份，或者把空间搬到另一台 Mac 上。操作前请先关闭空间中的程序。
  • 从归档恢复：双击 .onwinspace 文件，或者在“文件”菜单中选择“从归档恢复空间…”。
  • “删除…”：空间连同其中的所有内容会被移到废纸篓。在倒空废纸篓之前，都可以把它找回来。
  • “在访达中显示”：打开空间所在的文件夹。空间页面上的“打开 C: 盘”按钮会打开它的 C: 盘。

空间设置

点按空间页面上的“设置”按钮，或者通过菜单“空间”→“空间设置…”打开。最有用的几项：

  • “Windows 版本”（“通用”部分）：程序“看到”的是哪个版本的 Windows。老游戏有时需要 Windows 7 或 XP。
  • “图形”：游戏画面是怎样绘制的。通常最好保持“自动”。详情请见“图形”一节。
  • “Metal HUD”：在游戏画面上显示帧率，方便查看游戏运行得是否流畅。
  • “高分辨率（Retina）”：画面更清晰，但游戏会变慢，老程序里的文字也会变小。如果拿不准，就不要开启。
  • “MSync”（“性能”部分）：让游戏运行得更快。建议保持开启。
  • “报告支持 AVX”：有些新游戏需要它，否则无法启动。
  • “组件”：空间里已经装了什么、还可以添加什么。见“组件”一节。
  • “Launchpad 快捷方式”：见“快捷方式”一节。

如果在空间运行时更改 MSync 或 Retina，onwin 会提醒您：设置要在空间重新启动后才生效，空间中的所有程序都会被关闭。

安装程序

从目录安装

目录就是左侧的“应用和游戏”（或者菜单“空间”→“从目录安装…”）。里面是现成的配方。配方是给 onwin 的一份说明：创建什么样的空间、安装哪些组件、运行哪个安装程序。您只需点按“安装…”并选择安装位置，其余的事 onwin 会自己完成。

“游戏启动器”部分有 Steam、Epic Games Launcher、GOG Galaxy 和 Battle.net。顶部有搜索栏。

自己的安装程序（.exe 或 .msi）

目录里没有您要的程序？那就从文件安装：

  • 把文件拖到 onwin 窗口中；
  • 或者在目录的“安装自己的程序”卡片中点按“选择安装程序…”；
  • 或者在桌面上点按“安装”→“从文件…”。

选择一个空间（新建的或已有的），然后点按“运行安装程序”。如果 onwin 问“要做什么”，安装程序请选“安装”，不需要安装的现成程序请选“运行”。安装完成后，onwin 会自动找到新程序，并把它显示在桌面上。

“我的应用”

安装完自己的程序后，onwin 会建议把它保存到“我的应用”。这些是您自己在目录中的配方：下次一键就能安装同一个程序。也可以手动创建新配方：在“添加应用”卡片中点按“创建…”。配方可以分享：“导出…”会把它保存为 .onwinrecipe 文件，“导入…”则会添加别人的配方。导入不会运行任何东西，您会先看到配方里有什么。

不安装，直接运行 .exe

点按窗口顶部的“运行 .exe”（或者按 ⌘ + O），选择文件和空间。也可以直接把文件拖到窗口中。

固定程序

空间页面上会列出它的程序。右键点按某个程序并选择“固定”，它就会出现在“已固定”部分。对于已固定的程序，可以在“属性…”中设置自己的名称、图形、启动参数和环境变量。如果列表里没有您要的程序，请在“更多”菜单中选择“将程序添加到列表…”。

如果桌面上的某个磁贴碍事，可以在它的菜单中选择“从桌面隐藏”。点按“显示隐藏项”即可恢复。

“带参数运行…”

每个程序和游戏的菜单里都有这一项。它会用特殊设置把程序运行一次：自定义启动参数、换一种图形、Metal HUD。空间的设置不会因此改变。想试试某项改动是否有用时很方便。如果有用，勾选“存储为程序”，onwin 就会记住这些设置。

卸载程序

菜单“空间”→“卸载程序…”会打开已安装程序的列表，并运行它们的卸载程序。想一次清除所有内容，直接删除整个空间即可。

Steam 与游戏

  1. 安装 Steam

    目录 →“Steam”→“安装…”。onwin 会创建名为“Steam”的空间，并立即为它设置好 Steam 在 Mac 上需要的选项。

  2. 登录账户

    安装完成后，Steam 会自动更新并要求登录。像平常一样登录即可，用户名和密码是在 Steam 自己的窗口里输入的。

  3. 下载游戏

    像在 Windows 上一样，从 Steam 库中安装游戏。装好的游戏会以磁贴的形式出现在 onwin 桌面上，也会出现在空间页面的“Steam 游戏”部分。

  4. 开始游戏

    双击磁贴，选择“开始游戏”。onwin 会通过 Steam 启动游戏。

游戏磁贴上会显示它当前的状态：“正在运行”、“正在下载”或“需要更新”。游戏的菜单（右键点按）中有“显示游戏文件夹”、“验证文件完整性”、“Steam 商店页面”和“通过 Steam 卸载…”。空间页面上的“打开 Steam”按钮会打开 Steam 本身。

在 Windows 内核层面运行反作弊保护的游戏（部分网络射击游戏）通常无法在 onwin 中运行。这是 Wine 的限制，与您的 Mac 无关。

图形：D3DMetal、DXMT、DXVK

Windows 游戏通过 DirectX 绘制画面，这是 Windows 的技术。Mac 上没有 DirectX，所以 onwin 会把 DirectX“翻译”成 Mac 的语言（Metal）。这样的翻译器有好几种，不同的游戏适合不同的翻译器。在 onwin 里，这一项叫作“图形”。

自动
onwin 会自动选择最合适的方案。建议先用这个。
D3DMetal
来自 Apple。对使用 DirectX 11 和 12 的新游戏来说是最佳选择。需要单独安装（见下文）。
DXMT
开源的翻译器，适用于 DirectX 10 和 11 游戏。
DXVK
适用于 DirectX 9–11 游戏。如果用其他方案游戏运行不起来，可以试试它。
WineD3D (OpenGL)
兼容性最好，但速度最慢。适合老游戏。

如何选择

  • 先保持“自动”。安装了 D3DMetal 后，onwin 会优先选择它。
  • 游戏无法启动、黑屏或画面出错时，换一种方案试试。最快的办法是用“带参数运行…”：这样不会改动空间的设置。
  • 找到合适的方案后，固定这个程序，在“属性…”的“此程序的图形”中选择它。或者在空间设置中更改“图形”，这样空间里的所有程序都会使用它。

图形设置的更改会在下次启动程序时生效。

如何安装 D3DMetal

D3DMetal 是 Game Porting Toolkit 的一部分，这是 Apple 为游戏开发者提供的一套工具。Apple 只在您用 Apple ID 登录后才提供下载，普通的免费账户就可以。因此 onwin 不能把 D3DMetal 打包在内，也从不分发它：这套工具是在您的 Mac 上从 Apple 网站下载的。

  1. 点按“安装 D3DMetal”

    这个按钮在目录里（“组件”部分的“D3DMetal (Game Porting Toolkit)”卡片），在菜单“空间”→“安装 D3DMetal…”中，也在 onwin 设置的“D3DMetal”标签页里。

  2. 用 Apple ID 登录

    会打开“安装 D3DMetal — 登录 Apple ID”窗口，里面是 Apple 的网页。密码是在 Apple 的网页上输入的，onwin 看不到也不会保存它。如果 Apple 要求您接受开发者协议，请在同一页面上接受。

  3. 稍等片刻

    onwin 会自动下载最新版本的 Game Porting Toolkit，并从中安装 D3DMetal，所有空间都能直接使用。这一步只需要做一次。

不想在 onwin 窗口里登录？点按“在浏览器中打开”，在 Apple 网站上把 Game Porting Toolkit（.dmg）下载到“下载”文件夹，onwin 会自己找到这个文件。如果文件已经下载好了，可以点按“手动选择…”来选中它。

组件

组件是许多游戏和程序都需要的 Windows 附加部分：Visual C++ 运行库、DirectX、.NET、字体等等。在普通的 Windows 上，它们会随游戏一起安装。在 onwin 中，这一切都会自动完成。

自动安装

程序第一次启动前，onwin 会检查它缺少哪些库，并在后台悄悄装好。如果程序仍然因为缺少某个库而没能启动，onwin 会补装缺少的部分，然后再启动一次。所有内容都从官方服务器（Microsoft 及其他作者）下载。

这项功能默认开启。可以在 onwin 设置的“通用”标签页中关闭，也可以在单个空间的设置中关闭“自动安装所需组件”。关闭后，onwin 只会提示缺少什么。

手动安装

打开目录中的“组件”部分。选择一个组件，点按“添加…”，然后选择空间。另一种方式是在空间设置的“组件”部分操作。

有时空间页面上会出现“游戏可能需要”的提示，并附有组件列表。点按“全部安装”，onwin 就会把它们装好。

Launchpad 和 Dock 中的快捷方式

任何 Windows 程序都可以像普通的 Mac 应用一样，从 Launchpad（启动台）、聚焦搜索或 Dock（程序坞）中打开，无需先进入 onwin。

  • 单个程序：右键点按它（在桌面上或空间页面上），选择“在 Launchpad 中创建快捷方式”。
  • 空间中的所有程序：在空间设置的“Launchpad 快捷方式”部分，开启“自动创建快捷方式”。onwin 会为“开始”菜单中的每个程序创建快捷方式，并自动移除已卸载程序的快捷方式。
  • 放到 Dock 中：像对待任何 Mac 应用一样，把快捷方式从 Launchpad 或快捷方式文件夹拖到 Dock 中。

快捷方式位于 ~/Applications/onwin/ 文件夹中，每个空间一个子文件夹。要移除快捷方式，请在程序的菜单中选择“从 Launchpad 移除快捷方式”。

遇到问题怎么办

请按顺序尝试。大多数情况下，第一步或第二步就能解决问题。

  1. 重新启动空间

    有时程序会在后台“卡住”。在空间页面上点按“全部结束”（或者菜单“空间”→“结束空间中的所有程序”），然后再次启动程序。

  2. 换一种图形

    黑屏、启动时闪退、画面出错：用“带参数运行…”启动程序，并在“图形”中选择另一种方案。详情请见“图形”一节。

  3. 安装建议的组件

    如果程序没能启动，onwin 可能会显示“……没能启动，以下方法也许有帮助”的提示，并附上组件列表。点按“全部安装”。

  4. 更改 Windows 版本

    老游戏有时需要 Windows 7 或 XP。可以在空间设置的“Windows 版本”中更改。

  5. 查看日志

    日志是一个文本文件，onwin 会把程序启动时发生的一切都记在里面。出错的原因通常能在这里找到。打开日志的方法：左侧的“日志”栏目、空间页面上的“日志”按钮，或者错误信息中的“显示日志”按钮。日志文件本身位于 ~/Library/Logs/onwin 文件夹中。可以点按“拷贝”复制日志，附在问题报告里。

通常无法运行的情况

  • 反作弊系统在 Windows 内核层面运行的游戏（部分网络射击游戏）。
  • 需要专用设备驱动的程序：某些打印机、扫描仪、加密狗和少见的控制器。
  • 会检查自己是否运行在“真正的”Windows 上、否则拒绝启动的程序。

其他大多数程序都能运行。如果没能成功，请告诉我们，这能帮助我们把 onwin 做得更好。

报告问题

用简单的话描述发生了什么，不需要技术细节，我们会弄清楚的。请注意：Telegram 支持群组使用俄语交流；如果您更习惯用英语，可以在 GitHub Issues 中提交问题。

更新与卸载

更新 onwin

在“终端”中运行安装时用过的同一条命令。它只会下载有变化的部分。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

如果您是通过 DMG 磁盘映像安装的 onwin，请在“安装”页面下载新的磁盘映像。

卸载 onwin

这条命令会删除应用和引擎。您的空间（程序、游戏和存档）会保留下来。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

如果连空间也要删除，请使用下面这条命令。“终端”会再次询问您是否确定要删除。此操作无法撤销：空间中的程序和存档都会消失。

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge

进阶：onwinctl

onwinctl 是一个“终端”工具：onwin 窗口里能做的事，都可以用命令完成。普通用户用不到它。输入 onwinctl help 可以查看全部命令。

如果找不到 onwinctl 命令，可以直接从应用中运行它：/Applications/Onwin.app/Contents/MacOS/onwinctl。

检查安装情况

onwinctl status
已安装的内容：Rosetta、引擎、D3DMetal
onwinctl engines
Wine 引擎列表

空间

onwinctl spaces
空间列表
onwinctl create <名称> [--win win10] [--backend auto|d3dmetal|dxmt|dxvk|wined3d]
创建空间
onwinctl info <名称>
空间设置
onwinctl set <名称> <参数> <值> [--restart]
更改设置：backend、win、msync、retina、hud、avx、dxr、metalfx、debug、launchers、autocomponents、env:名称、dll:名称
onwinctl archive <名称> <文件.onwinspace>
把空间打包为归档
onwinctl restore <文件.onwinspace> [名称]
从归档恢复
onwinctl delete <名称>
把空间移到废纸篓

安装与运行

onwinctl catalog
应用和组件目录
onwinctl install <应用> [--space 名称]
从目录安装，例如 steam
onwinctl run <空间> <文件.exe|.msi|.lnk> [参数...]
运行并等待结束；所需组件会自动安装（加 --no-auto-components 则不安装）
onwinctl programs <空间>
找到的程序
onwinctl pin <空间> <路径> [名称]
固定程序（unpin 取消固定）
onwinctl wine <空间> <命令>
运行 Wine 工具，例如 winecfg、regedit、cmd
onwinctl uninstall-list <空间>
可以卸载的程序（uninstall 用于卸载）

Steam

onwinctl steam-games <空间>
空间中的 Steam 游戏
onwinctl steam-launch <空间> <appid|名称>
通过 Steam 启动游戏
onwinctl steam-install <空间> <appid>
在 Steam 中打开游戏安装

停止程序

onwinctl running <空间>
空间是否正在运行
onwinctl shutdown <空间>
正常关闭所有程序（10 秒后强制关闭）
onwinctl kill <空间>
强制结束所有程序
onwinctl reboot <空间>
在空间中“重启 Windows”

图形与组件

onwinctl d3dmetal-import <GPTK 路径>
从下载好的 Game Porting Toolkit（.dmg 或宗卷）导入 D3DMetal
onwinctl d3dmetal-fetch
从“下载”文件夹导入已下载的 Game Porting Toolkit；用 Apple ID 登录请在 onwin 应用中进行
onwinctl components [空间]
组件列表（✓ 表示已安装）
onwinctl component <空间> <组件>[,...]
安装组件，例如 vcrun2026
onwinctl advise <空间|-> <文件.exe>
程序缺少哪些组件
onwinctl advise-log <日志.log>
根据启动失败的日志给出建议

快捷方式与自定义配方

onwinctl launcher <空间> <程序>
为 Launchpad 和 Dock 创建快捷方式
onwinctl launchers [空间]
快捷方式列表
onwinctl launcher-remove <空间> <程序>
移除快捷方式
onwinctl recipe list
“我的应用”中您自己的配方
onwinctl recipe export <id> <文件.onwinrecipe>
把配方保存为文件（recipe import 用于从文件添加）
