支持 onwin

onwin 免费且开源。如果它对您有帮助，欢迎支持项目继续发展，任何金额都很重要。

捐款的用途

开发时间

构建引擎、支持新游戏、修复错误以及解答问题。

测试硬件

不同型号的 Mac 和不同版本的 macOS，确保游戏不只在一台电脑上测试过。

Apple 证书

Developer ID 用于为应用签名和公证：这样从 DMG 安装时，就不再需要在设置中多走几步。

支持方式

选择方便的方式即可，一次性或定期捐助都可以。钱包地址可以用按钮复制；转账前请确认选择了正确的网络。

不花钱也能帮忙

告诉我们哪些游戏能运行、哪些不能，在 GitHub Issues 上报告错误（可使用英语），为项目点亮星标，或者把它推荐给朋友。
