onwin

测试版 onwin 仍在开发中：很多功能已经可用，但仍可能出错。遇到问题请告诉我们。

在您的 Mac 上运行 Windows 游戏和程序

有一款只支持 Windows 的游戏或程序，而您用的是 Mac？onwin 可以直接在 macOS 中运行它：无需安装 Windows，无需额外分区，也无需重启。

免费安装 工作原理

免费，无广告、无订阅 · 搭载 Apple 芯片的 Mac（M1 及更新机型） · macOS 14 及更新版本

onwin 适合谁、能做什么

想玩一款没有 Mac 版的游戏

Steam 和其他商店里的很多游戏只有 Windows 版。在 onwin 中安装 Windows 版 Steam，就能像普通应用一样直接在 Mac 上运行这些游戏。

需要一个只有 Windows 版的程序

工作用的小工具、用惯了的老程序、光盘里的安装程序……onwin 双击就能打开普通的 .exe 文件。

不想安装 Windows，也不想来回重启

不用购买 Windows，不用给硬盘分区，也不用开虚拟机。Windows 程序会在窗口中打开，和您的 Mac 应用并排使用。

这对我的 Mac 安全吗？

每个程序都在自己的“空间”里运行。空间就是一个单独的文件夹，有自己的 C: 盘。不满意的话，删除这个空间，程序就不会留下任何痕迹。onwin 不会改动 macOS 的系统文件。

实话实说：哪些可能无法运行。 能运行的程序非常多，但不是全部：带有严格反作弊保护的游戏（部分在线射击游戏），以及需要专用设备驱动的程序，通常无法运行。验证方法很简单：onwin 是免费的，装上试试就知道了。

功能

一切只为让程序顺利运行

onwin 会替您配置好 Windows 环境，您只需选择游戏或安装程序。

空间

每个空间都是一个独立的 Windows 环境，有自己的 C: 盘和程序。游戏之间互不干扰，不需要的空间可以整个删除。

Steam 与游戏磁贴

安装 Windows 版 Steam 后，游戏库中的游戏会以磁贴的形式出现在 onwin 的桌面上。磁贴会显示游戏当前是否正在运行。

组件自动安装

内置 DirectX、Visual C++ 运行库、字体等组件的目录。onwin 会在程序首次运行前安装它需要的组件；如果启动失败，还会补装缺少的部分。

图形方案任选

D3DMetal、DXMT 或 DXVK，可以为每个程序单独选择。D3DMetal 是 Apple 的 Game Porting Toolkit 的一部分：您用自己的 Apple ID 登录后，onwin 会从 Apple 网站下载它。

Launchpad 和 Dock 中的快捷方式

Windows 程序会拥有自己的快捷方式，像普通 Mac 应用一样直接打开，无需先进入 onwin。

onwinctl

命令行工具：在“终端”和脚本中管理空间、安装和运行程序。

自有引擎

Wine 11（含 CodeWeavers 的补丁）、DXVK、DXMT、MoltenVK 和 GStreamer，全部由开源代码专门为 onwin 构建。

自由且免费

代码以 GPL-3.0 许可证开源。没有广告、没有订阅，也不强制注册账号。

工作原理

快速上手

只需四个简单步骤，就能在 Mac 上运行 Windows 游戏。

  1. 安装 onwin

    从“安装”页面复制一条命令，粘贴到“终端”中。它会安装应用以及所需的一切。

  2. 打开 onwin

    如果 onwin 提示安装 Rosetta 2，请点按“安装 Rosetta”。这是 Apple 提供的免费转译工具，没有它 Windows 程序无法运行。

  3. 安装 Steam 或您自己的程序

    点按“安装 Steam”，或者直接把 .exe 安装程序拖到 onwin 窗口中。onwin 会自动为它创建一个单独的“空间”，相当于属于它自己的小 Windows。

  4. 开始游戏

    游戏和程序会以磁贴的形式出现在 onwin 的“桌面”上。双击磁贴即可运行。

内部原理

这不是模拟一整台电脑：Windows 程序就像普通的 macOS 进程一样运行。

  • Windows 程序或游戏.exe
  • Wine 11Windows 调用 → macOS 调用
  • D3DMetal · DXMT · DXVKDirectX → Metal
  • Rosetta 2x86-64 代码 → Apple 芯片
  • macOS 与 Metal您的 Mac
