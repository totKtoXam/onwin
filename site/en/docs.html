Documentation

Quick start

Five steps from installing onwin to your first game. You don’t need to set anything up by hand.

  1. Install onwin

    Open Terminal: press ⌘ + Space, type “Terminal” and press Return. Paste this command and press Return again:

    curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

    The command installs the onwin app and its engine. The engine is the part that knows how to run Windows programs. The installer’s messages are in Russian for now, but there’s nothing to choose: just wait until it finishes. Other ways to install are described on the Install page.

  2. Open onwin

    onwin is in your Applications folder. If your Mac doesn’t have Rosetta 2, onwin shows a window saying that onwin needs Rosetta 2. Rosetta 2 is a free translator from Apple: without it, Windows programs can’t run on a Mac with an Apple processor. Click “Install Rosetta”. macOS may ask for your password — that’s normal.

    Next you’ll see the main window. On the left is a list of sections: “Desktop”, the “Apps & Games” catalog, your spaces, running programs and logs. On the right is the “Desktop”: this is where all your Windows games and programs will appear.

  3. Install Steam or your own program

    Steam in one click. On the empty desktop, click “Install Steam”. Or open “Apps & Games” on the left, find Steam and click “Install…”. onwin prepares everything and starts the installer for you.

    Your own program — an installer file, .exe or .msi. There are three ways:

    • drag the file straight into the onwin window;
    • drag the file onto the onwin icon in the Dock, or open it with onwin (in Finder: right-click → “Open With” → onwin);
    • in the catalog, under “Your Own Program”, click “Choose Installer…”.

    onwin asks where to install the program: into a new space or into one you already have. If you’re not sure, choose a new one.

  4. Launch your game

    Everything you install appears as a tile on the onwin “Desktop”. Double-click a tile and the program or game starts. Games you download in Steam also show up here as separate tiles.

  5. For new games, turn on D3DMetal

    Modern games (DirectX 12, and often DirectX 11) work best with D3DMetal — Apple’s graphics translation. onwin can’t bundle it, but it can install it for you: open the catalog, the “Components” section, the “D3DMetal (Game Porting Toolkit)” card, and click “Install D3DMetal”. You’ll need to sign in with a free Apple ID. More in the Graphics section.

    If a game needs D3DMetal and it isn’t installed yet, onwin offers to install it before launching the game.

Spaces

A space is a separate “Windows computer” inside onwin. It has its own C: drive, its own programs, settings and saves. Spaces don’t interfere with each other. If something breaks or you no longer need it, delete the space and the program leaves no trace.

Usually one space per launcher (for example, “Steam”) or per program is enough. When you install something from the catalog, onwin creates the space for you.

Create a space

On the left, in the “Spaces” section, click “Create Space…”. Or use the “New Space” button at the top of the window, or press ⌘ + N. Enter a name and a Windows version. Windows 10 suits most games. You can leave the graphics on “Automatic”.

What you can do with a space

Right-click a space in the list on the left. The same commands are in the “More” menu on the space’s page.

  • “Rename…” — give it another name. Close the space’s programs first.
  • “Duplicate” — make an independent copy with all installed programs. Handy for trying something without risking the working version.
  • “Archive…” — pack the space into a single .onwinspace file. It’s a backup, or a way to move the space to another Mac. Close the space’s programs first.
  • Restore from an archive — double-click the .onwinspace file, or choose “Restore Space from Archive…” in the “File” menu.
  • “Delete…” — the space and everything in it go to the Trash. You can get it back until you empty the Trash.
  • “Show in Finder” — open the space’s folder. The “Open C: Drive” button on the space’s page opens its C: drive.

Space settings

Open them with the “Settings” button on the space’s page, or via the “Space” menu → “Space Settings…”. The most useful ones:

  • “Windows Version” (“General” section) — which Windows the programs “see”. Old games sometimes need Windows 7 or XP.
  • “Graphics” — how games draw their picture. It’s usually best to leave it on “Automatic”. More in the Graphics section.
  • “Metal HUD” — shows the frame rate on top of the game. Handy for checking how smoothly a game runs.
  • “High Resolution (Retina)” — a sharper picture, but games run slower and text in old programs gets tiny. If you’re not sure, leave it off.
  • “MSync” (“Performance” section) — makes games run faster. We recommend keeping it on.
  • “Report AVX Support” — needed by some new games that won’t start without it.
  • “Components” — what’s already installed in the space and what you can add. See the Components section.
  • “Launchpad Shortcuts” — see the Shortcuts section.

If the space is running and you change MSync or Retina, onwin warns you: the setting takes effect after the space restarts, and all its programs will close.

Installing programs

From the catalog

The catalog is the “Apps & Games” section on the left (or the “Space” menu → “Install from Catalog…”). It holds ready-made recipes. A recipe is a set of instructions for onwin: which space to create, which components to install and which installer to run. You click “Install…”, choose where to install, and onwin does the rest.

The “Game Launchers” section has Steam, Epic Games Launcher, GOG Galaxy and Battle.net. There’s a search field at the top.

Your own installer (.exe or .msi)

Program not in the catalog? Install it from a file:

  • drag the file into the onwin window;
  • or, in the catalog, on the “Install Your Own Program” card, click “Choose Installer…”;
  • or, on the desktop, click “Install” → “From File…”.

Choose a space — a new one or one you’ve already created — and click “Run Installer”. If onwin asks “What to do”, choose “Install” for an installer or “Run” for a ready-to-use program that doesn’t need installing. When the installation finishes, onwin finds the new program and shows it on the desktop.

“My Apps”

After you install your own program, onwin offers to save it to “My Apps”. These are your own recipes in the catalog: next time you can install the same program in one click. You can also make a new recipe by hand — the “Add App” card, the “Create…” button. Recipes can be shared: “Export…” saves one to a .onwinrecipe file, and “Import…” adds someone else’s. Importing doesn’t run anything — you see what’s in the recipe first.

Run an .exe without installing

Click “Run .exe” at the top of the window (or press ⌘ + O), choose the file and a space. You can also simply drag the file into the window.

Pin a program

A space’s page shows its programs. Right-click a program and choose “Pin”. It moves to the “Pinned” section. For a pinned program, “Properties…” lets you set your own name, graphics, launch options and environment variables. If the program you need isn’t in the list, choose “Add Program to List…” in the “More” menu.

If a tile is in the way on the desktop, choose “Hide from Desktop” in its menu. The “Show Hidden” button brings hidden tiles back.

“Run with Options…”

This item is in the menu of every program and game. It runs the program once with special settings: your own launch arguments, different graphics, Metal HUD. The space’s settings stay the same. Handy for testing whether something helps. If it does, tick “Save as Program” and onwin will remember these settings.

Uninstall a program

The “Space” menu → “Uninstall Program…” opens a list of installed programs and runs their uninstaller. To remove everything at once, delete the space itself.

Steam and games

  1. Install Steam

    Catalog → “Steam” → “Install…”. onwin creates a “Steam” space and right away applies the settings Steam needs on a Mac.

  2. Sign in

    After installing, Steam updates itself and asks you to sign in. Sign in as usual — you type your login and password in Steam’s own window.

  3. Download a game

    Install a game from your Steam library, just like on Windows. When it’s ready, the game appears as a tile on the onwin desktop and in the “Steam Games” section on the space’s page.

  4. Play

    Double-click the tile — “Play”. onwin launches the game through Steam for you.

A game’s tile shows what’s happening with it: “Running”, “Downloading” or “Update Required”. The game’s menu (right-click) has “Show Game Folder”, “Verify Integrity of Game Files”, “Steam Store Page” and “Uninstall via Steam…”. The “Open Steam” button on the space’s page opens Steam itself.

Games with anti-cheat that works at the Windows kernel level (some online shooters) usually don’t run in onwin. This is a limitation of Wine, not of your Mac.

Graphics: D3DMetal, DXMT, DXVK

Windows games draw their picture with DirectX, a Windows technology. Macs don’t have it, so onwin “translates” DirectX into the Mac’s language (Metal). There are several translators, and different games work better with different ones. In onwin this is called “Graphics”.

Automatic
onwin picks the best option itself. Start with this one.
D3DMetal
from Apple. The best choice for new DirectX 11 and 12 games. Installed separately (see below).
DXMT
an open-source translator for DirectX 10 and 11 games.
DXVK
for DirectX 9–11 games. Try it if a game won’t run with the other options.
WineD3D (OpenGL)
the most compatible, but the slowest. Good for old games.

How to choose

  • Start with “Automatic”. When D3DMetal is installed, onwin picks it first.
  • The game won’t start, the screen is black or the picture is glitchy — try another option. The quickest way is “Run with Options…”: it doesn’t change the space’s settings.
  • Found an option that works? Pin the program and, in “Properties…”, choose it under “Graphics for This Program”. Or change “Graphics” in the space settings — then all programs in the space will use it.

Graphics changes take effect the next time the program starts.

How to install D3DMetal

D3DMetal is part of the Game Porting Toolkit, Apple’s kit for game developers. Apple only provides it after you sign in with an Apple ID. A regular free account is fine. That’s why onwin can’t bundle D3DMetal and never distributes it: the kit is downloaded from Apple’s website on your Mac.

  1. Click “Install D3DMetal”

    The button is in the catalog (the “Components” section, the “D3DMetal (Game Porting Toolkit)” card), in the “Space” menu → “Install D3DMetal…”, and in onwin’s settings on the “D3DMetal” tab.

  2. Sign in with your Apple ID

    A window titled “Install D3DMetal — Apple ID Sign-In” opens with Apple’s page. You type your password on Apple’s page — onwin doesn’t see it or store it. If Apple asks you to accept the developer agreement, accept it right there.

  3. Wait

    onwin downloads the latest Game Porting Toolkit and installs D3DMetal from it — for all spaces at once. You only need to do this once.

Don’t want to sign in inside the onwin window? Click “Open in Browser” and download the Game Porting Toolkit (.dmg) from Apple’s website into your Downloads folder — onwin will find the file by itself. If you’ve already downloaded it, select it with the “Choose Manually…” button.

Components

Components are extra parts of Windows that many games and programs need: Visual C++ libraries, DirectX, .NET, fonts and more. On a regular Windows PC they’re installed together with the game. In onwin this happens automatically.

Automatically

Before a program’s first launch, onwin checks which libraries it’s missing and quietly installs them. If the program still fails to start because a library is missing, onwin installs what’s missing and launches it again. Everything is downloaded from official servers (Microsoft and other authors).

This is on by default. You can turn it off in onwin’s settings on the “General” tab, or in the settings of a single space with the “Install required components automatically” option. Then onwin will only tell you what’s missing.

Manually

Open the catalog, the “Components” section. Choose a component, click “Add…” and pick a space. Another way is the space settings, the “Components” section.

Sometimes the space’s page shows a hint, “The game may need”, with a list of components. Click “Install All” and onwin installs them.

Shortcuts in Launchpad and the Dock

Any Windows program can be opened like a regular Mac app — from Launchpad, Spotlight or the Dock, without opening onwin.

  • For one program: right-click it (on the desktop or on the space’s page) and choose “Create Launchpad Shortcut”.
  • For all programs in a space: in the space settings, in the “Launchpad Shortcuts” section, turn on “Create shortcuts automatically”. onwin makes a shortcut for every program in the Start menu and removes shortcuts of uninstalled programs by itself.
  • In the Dock: drag a shortcut from Launchpad or from the shortcuts folder to the Dock, like any Mac app.

Shortcuts are stored in the ~/Applications/onwin/ folder, one folder per space. To remove a shortcut, choose “Remove Launchpad Shortcut” in the program’s menu.

If something doesn’t work

Try these in order. The first or second step helps most often.

  1. Restart the space

    Sometimes a program “hangs” in the background. On the space’s page, click “Quit All” (or the “Space” menu → “Quit All Programs in Space”) and start the program again.

  2. Try different graphics

    Black screen, a crash at startup, a glitchy picture — start the program with “Run with Options…” and choose another option under “Graphics”. More in the Graphics section.

  3. Install the suggested components

    If a program fails to start, onwin may show a hint, “…didn’t start — here’s what may help”, with a list of components. Click “Install All”.

  4. Change the Windows version

    Old games sometimes need Windows 7 or XP. You can change this in the space settings, under “Windows Version”.

  5. Look at the log

    A log is a text file where onwin writes down everything that happens when a program starts. The cause of an error is usually visible there. Logs open in the “Logs” section on the left, with the “Logs” button on the space’s page, or with the “Show Log” button in an error message. The files themselves are in the ~/Library/Logs/onwin folder. You can copy a log with the “Copy” button and attach it to your problem report.

What usually doesn’t work

  • Games with anti-cheat that works at the Windows kernel level (some online shooters).
  • Programs that need their own device drivers: some printers, scanners, copy-protection dongles, rare controllers.
  • Programs that check that they’re running on “real” Windows and refuse to start otherwise.

Most other things run. If something doesn’t work for you, let us know — it helps make onwin better.

Report a problem

Describe what happened in plain words — no technical details needed. We’ll figure it out. Our Telegram support chat is in Russian; if you prefer English, open an issue on GitHub.

Updating and uninstalling

Update onwin

Run the same command in Terminal that you used to install it. It downloads only what has changed.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

If you installed onwin from the DMG disk image, download the new image on the Install page.

Uninstall onwin

This command removes the app and the engine. Your spaces — programs, games and saves — stay where they are.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

To delete your spaces as well, use this command. Terminal will ask whether you’re sure (the question is in Russian; answer it as the prompt shows). This can’t be undone: the programs and saves inside your spaces will be gone.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge

For advanced users: onwinctl

onwinctl is a tool for Terminal: everything the onwin window does, but with commands. Regular users don’t need it. onwinctl help shows the full list of commands.

If the onwinctl command isn’t found, run it from inside the app: /Applications/Onwin.app/Contents/MacOS/onwinctl.

Check that everything is installed

onwinctl status
what’s installed: Rosetta, the engine, D3DMetal
onwinctl engines
list of Wine engines

Spaces

onwinctl spaces
list of spaces
onwinctl create <name> [--win win10] [--backend auto|d3dmetal|dxmt|dxvk|wined3d]
create a space
onwinctl info <name>
a space’s settings
onwinctl set <name> <setting> <value> [--restart]
change a setting: backend, win, msync, retina, hud, avx, dxr, metalfx, debug, launchers, autocomponents, env:NAME, dll:NAME
onwinctl archive <name> <file.onwinspace>
pack a space into an archive
onwinctl restore <file.onwinspace> [name]
restore from an archive
onwinctl delete <name>
move a space to the Trash

Install and run

onwinctl catalog
catalog of apps and components
onwinctl install <app> [--space name]
install from the catalog, for example steam
onwinctl run <space> <file.exe|.msi|.lnk> [arguments...]
run and wait; required components install automatically (--no-auto-components turns this off)
onwinctl programs <space>
programs found in the space
onwinctl pin <space> <path> [name]
pin a program (unpin to unpin)
onwinctl wine <space> <command>
run a Wine tool, for example winecfg, regedit, cmd
onwinctl uninstall-list <space>
programs that can be uninstalled (uninstall to uninstall)

Steam

onwinctl steam-games <space>
Steam games in the space
onwinctl steam-launch <space> <appid|title>
launch a game through Steam
onwinctl steam-install <space> <appid>
open a game’s installation in Steam

Stop programs

onwinctl running <space>
whether the space is running
onwinctl shutdown <space>
close all programs gently (forcefully after 10 s)
onwinctl kill <space>
force-quit all programs
onwinctl reboot <space>
“restart Windows” in the space

Graphics and components

onwinctl d3dmetal-import <path to GPTK>
import D3DMetal from a downloaded Game Porting Toolkit (.dmg or volume)
onwinctl d3dmetal-fetch
import a Game Porting Toolkit you’ve already downloaded to Downloads; Apple ID sign-in happens in the onwin app
onwinctl components [space]
list of components (✓ — installed)
onwinctl component <space> <component>[,...]
install a component, for example vcrun2026
onwinctl advise <space|-> <file.exe>
which components a program is missing
onwinctl advise-log <log.log>
what the log of a failed launch suggests

Shortcuts and your own recipes

onwinctl launcher <space> <program>
create a shortcut for Launchpad and the Dock
onwinctl launchers [space]
list of shortcuts
onwinctl launcher-remove <space> <program>
remove a shortcut
onwinctl recipe list
your recipes from “My Apps”
onwinctl recipe export <id> <file.onwinrecipe>
save a recipe to a file (recipe import adds one from a file)
