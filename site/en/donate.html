Support onwin

onwin is free and open source. If it has been useful to you, help the project grow — any amount makes a difference.

What donations pay for

Development time

Building the engine, supporting new games, fixing bugs and answering questions.

Test hardware

Different Macs and macOS versions, so games are tested on more than one computer.

Apple certificate

A Developer ID to sign and notarize the app: then it can be installed from the DMG without workarounds in System Settings.

Ways to donate

Choose whatever is convenient — one-time and recurring donations are both welcome. You can copy a wallet address with its button; before sending, check that the right network is selected.

You can help without money, too

Tell us which games work for you and which don’t, report a bug in GitHub Issues, star the project or tell your friends about it.
