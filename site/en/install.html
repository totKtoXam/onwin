Install onwin

Two ways — pick whichever suits you. The result is the same: onwin in your Applications folder.

beta Only beta versions are available for now: onwin is still in development, and some things may be unstable. If you run into a problem, write to us.

Option 1

Download the app

A regular disk image (DMG), like other Mac apps. On first launch onwin downloads the Wine engine by itself, so it needs internet.

Download onwin (DMG) Latest release on GitHub

No internet on this Mac? Download the offline version: the Wine engine is already inside.

  1. Open the downloaded file

    You’ll find it in Downloads. Drag Onwin into the Applications folder.

  2. Open Onwin

    The first time, macOS will say it can’t verify the app. Click “Done”.

  3. Allow it to open, once

    System Settings → Privacy & Security → “Open Anyway” near the bottom. Why this is needed

Option 2

With Terminal no warnings

One command, and onwin installs itself — no steps in System Settings.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash

  1. Open Terminal

    Press ⌘ + Space, type “Terminal” and press Return.

  2. Paste the command

    Press ⌘ + V in the Terminal window.

  3. Press Return

    Wait for the word “Done”. If your Mac doesn’t have Rosetta 2, the installer will offer to install it.

For now the installer shows its messages in Russian. The steps are the same: when it finishes, it prints «Готово» (“Done”).

Updates

You get a new version the same way: a new disk image or the same command in Terminal. The command downloads only what has changed. In upcoming versions, onwin will offer updates by itself — with one button, without asking for permission again.

All releases, what’s new in them and commands to install any version are on the Updates page.

App
Onwin.app in the Applications folder (/Applications)
Wine engine
when installed with Terminal — separately, in ~/Library/Application Support/onwin/Engines; from the disk image — inside the app

You can read the install script before running it: install.sh.

Why macOS asks for permission

Apple checks (notarizes) apps only for developers with a paid membership — 99 dollars a year. onwin doesn’t have one yet, so the first time you open the app downloaded in a browser, macOS plays it safe and asks you to confirm that you trust it. You only need to do this once:

  1. Open Onwin from the Applications folder. A message will say that macOS can’t verify the app — click “Done”.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the Security section and click “Open Anyway” next to the message about Onwin. Confirm with your password or Touch ID.

onwin’s code is open — anyone can check it. Installing with Terminal skips these steps, because macOS doesn’t mark files downloaded by the command as “from the internet”. Donations will help pay for the Apple membership, and then this step will go away completely.

Uninstalling

This command removes the app and the engine. Your spaces — installed programs, games and saves — stay where they are.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall

To erase the spaces too, add --purge. This can’t be undone: the programs and saves inside the spaces will be deleted.

curl -fsSL https://OWNER.github.io/onwin/install.sh | bash -s -- --uninstall --purge
