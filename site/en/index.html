Windows games and apps on your Mac

Found a game or program that only runs on Windows, but you have a Mac? onwin runs it right in macOS — no Windows, no second drive, no restarting.

Install for free How it works

Free, no ads or subscriptions · Mac with an Apple chip (M1 or later) · macOS 14 or later

Who onwin is for

I want to play a game that isn’t on Mac

Many games on Steam and other stores come out for Windows only. Install the Windows version of Steam in onwin and run them right on your Mac, like regular apps.

I need a program that only exists for Windows

A tool for work, an old favorite program, an installer from a disc — onwin opens a regular .exe file with a double-click.

I don’t want to install Windows and keep restarting

No need to buy Windows, split your drive or keep a virtual machine around. Windows programs open in windows right next to your Mac apps.

Is it safe for my Mac?

Each program lives in its own “space” — a separate folder with its own C: drive. Don’t like something? Delete the space, and the program leaves no trace. onwin doesn’t touch macOS system files.

An honest word about what may not work. A lot runs, but not everything: games with strict anti-cheat protection (some online shooters) and programs that need drivers for their own devices usually don’t work. It’s easy to check: onwin is free — install it and try.

Features

Everything a program needs to just start

onwin takes care of setting up the Windows environment: all you do is pick a game or an installer.

Spaces

Each space is a separate Windows environment with its own C: drive and its own programs. Games don’t get in each other’s way, and a space you no longer need is deleted all at once.

Steam and game tiles

Install Steam for Windows, and the games in your library appear as tiles on the onwin Desktop. A tile shows whether the game is running right now.

Components, handled for you

A catalog of DirectX, Visual C++ libraries, fonts and other components. onwin installs what a program needs before its first launch — and fetches anything missing if a launch fails.

Your choice of graphics

D3DMetal, DXMT or DXVK — set separately for each program. D3DMetal is part of Apple’s Game Porting Toolkit: onwin downloads it from Apple’s website after you sign in with your Apple ID.

Shortcuts in Launchpad and the Dock

A Windows program gets its own shortcut and opens like a regular Mac app — without going into onwin.

onwinctl

A command-line tool: manage spaces, install and run programs from Terminal and scripts.

Its own engine

Wine 11 with CodeWeavers patches, DXVK, DXMT, MoltenVK and GStreamer — built from open source code specifically for onwin.

Free and open

The code is open under the GPL-3.0 license. No ads, no subscriptions, no required accounts.

How it works

Quick start

Four simple steps, and a Windows game is running on your Mac.

  1. Install onwin

    Copy one command from the Install page and paste it into Terminal. It installs the app and everything it needs.

  2. Open onwin

    If onwin asks you to install Rosetta 2, click “Install Rosetta”. It’s a free translator from Apple; Windows programs won’t start without it.

  3. Install Steam or your own program

    Click “Install Steam” — or just drag an .exe installer into the onwin window. onwin creates a separate “space” for it — its own little Windows.

  4. Play

    Games and programs appear as tiles on the onwin Desktop. Double-click a tile, and that’s it.

System requirements

What you need

A Mac with Apple Silicon

An M1 chip or later. Macs with Intel processors are not supported.

macOS 14 or later

Sonoma and later versions.

Rosetta 2

Needed for the x86 code of Windows programs. If it’s missing, the installer and the app will offer to install it.
