onwin

бета onwin әзірленіп жатыр: көп нәрсе қазірдің өзінде жұмыс істейді, бірақ қателер болуы мүмкін — бізге хабарлаңыз.

Mac компьютеріңізде Windows ойындары мен бағдарламалары

Ойын не бағдарлама тек Windows-қа арналған, ал сізде Mac бар ма? onwin оны тікелей macOS ішінде іске қосады — Windows-сыз, екінші дискісіз және компьютерді қайта жүктемей.

Тегін орнату Бұл қалай жұмыс істейді

Тегін, жарнамасыз және жазылымсыз · Apple процессоры бар Mac (M1 және жаңарақ) · macOS 14 және жаңарақ

onwin кімге және не үшін керек

Mac-қа шықпаған ойынды ойнағым келеді

Steam мен басқа дүкендердегі көптеген ойын тек Windows үшін шығады. onwin ішіне Windows-қа арналған Steam орнатыңыз — сонда оларды Mac-та кәдімгі қолданбалар сияқты іске қоса аласыз.

Тек Windows-та бар бағдарлама керек

Жұмысқа қажет утилита, ескі сүйікті бағдарлама, дисктегі орнатқыш — onwin кәдімгі .exe файлын екі рет шерткенде ашады.

Windows орнатып, компьютерді қайта жүктегім келмейді

Windows сатып алудың, дискіні бөлудің немесе виртуалды машина ұстаудың қажеті жоқ. Windows бағдарламалары Mac қолданбаларыңыздың қасында, жеке терезелерде ашылады.

Бұл менің Mac-ым үшін қауіпсіз бе?

Әр бағдарлама өз «кеңістігінде» — жеке C: дискісі бар бөлек қалтада тұрады. Бірдеңе ұнамаса, кеңістікті жойыңыз — бағдарламадан із қалмайды. onwin macOS жүйелік файлдарына тиіспейді.

Не жұмыс істемеуі мүмкін екенін ашық айтамыз. Өте көп нәрсе іске қосылады, бірақ бәрі емес: қатаң античит қорғанысы бар ойындар (кейбір онлайн-шутерлер) және өз құрылғыларының драйверлерін қажет ететін бағдарламалар әдетте жұмыс істемейді. Тексеру оңай: onwin тегін — орнатып, байқап көріңіз.

Мүмкіндіктер

Бағдарлама оңай іске қосылуы үшін бәрі бар

Windows ортасын баптауды onwin өзі атқарады: сізге тек ойынды немесе орнатқышты таңдау қалады.

Кеңістіктер

Әр кеңістік — өз C: дискісі мен бағдарламалары бар жеке Windows ортасы. Ойындар бір-біріне кедергі келтірмейді, ал керексіз кеңістік толығымен жойылады.

Steam және ойын тақтайшалары

Windows-қа арналған Steam орнатыңыз — кітапханадағы ойындар onwin жұмыс үстелінде тақтайша болып пайда болады. Тақтайша ойынның дәл қазір іске қосулы екенін көрсетеді.

Компоненттер өздігінен

DirectX, Visual C++ кітапханалары, қаріптер және басқа компоненттер каталогы. onwin бағдарламаға қажеттісін алғашқы іске қосу алдында орнатады, ал іске қосу сәтсіз болса, жетіспейтінін қосымша жүктеп алады.

Графиканы таңдауға болады

D3DMetal, DXMT немесе DXVK — әр бағдарлама үшін бөлек. D3DMetal Apple компаниясының Game Porting Toolkit құрамына кіреді: Apple ID арқылы кіргеннен кейін onwin оны Apple сайтынан жүктеп алады.

Launchpad пен Dock-тағы жарлықтар

Windows бағдарламасы өз жарлығын алады және onwin-ді ашпай-ақ кәдімгі Mac қолданбасы сияқты ашылады.

Өз қозғалтқышы

CodeWeavers патчтары бар Wine 11, DXVK, DXMT, MoltenVK және GStreamer — ашық бастапқы кодтан арнайы onwin үшін жиналған.

Еркін әрі тегін

Код GPL-3.0 лицензиясы бойынша ашық. Жарнамасыз, жазылымсыз және міндетті тіркелгісіз.

Бұл қалай жұмыс істейді

Жылдам бастау

Төрт қарапайым қадам — және Windows ойыны Mac-та іске қосылды.

  1. onwin орнатыңыз

    «Орнату» бетіндегі бір пәрменді көшіріп, Терминалға қойыңыз. Ол қолданбаны және оған қажеттінің бәрін орнатады.

  2. onwin ашыңыз

    onwin Rosetta 2 орнатуды сұраса, «Rosetta орнату» түймесін басыңыз. Бұл — Apple-дың тегін аудармашы бағдарламасы, онсыз Windows бағдарламалары іске қосылмайды.

  3. Steam немесе өз бағдарламаңызды орнатыңыз

    «Steam орнату» түймесін басыңыз немесе .exe орнатқыш файлын onwin терезесіне сүйреп апарыңыз. onwin ол үшін жеке «кеңістік» — өзінің шағын Windows-ын өзі жасайды.

  4. Ойнаңыз

    Ойындар мен бағдарламалар onwin «Жұмыс үстелінде» тақтайша болып пайда болады. Тақтайшаны екі рет шертсеңіз болғаны.

Ішінде не болады

Бүкіл компьютерді эмуляциялау жоқ: Windows бағдарламасы кәдімгі macOS процесі ретінде жұмыс істейді.

  • Windows бағдарламасы немесе ойын.exe
  • Wine 11Windows шақырулары → macOS шақырулары
  • D3DMetal · DXMT · DXVKDirectX → Metal
  • Rosetta 2x86-64 коды → Apple Silicon
  • macOS және Metalсіздің Mac
Көмек

Бірдеңе жұмыс істемей ме? Бізге жазыңыз

Не болғанын өз сөзіңізбен айтып беріңіз. Алдымен «Бір нәрсе істемесе» бөліміндегі кеңестерді қарап шығуға болады. Telegram-чат орыс тілінде жүргізіледі; ағылшын тілінде GitHub Issues арқылы жазуға болады.
